## 二、摘要口径实算（`omit_zero=True`）

| 量 | 慈溪润科 | 杭州小章 |
|---|---|---|
| 存货类别分布 | 自制半成品 5 | 自制半成品 4 / 产成品 1 / **原材料 1** |
| `x`（原材料行数量，命中行数） | **0**（0 行） | **400**（1 行） |
| `y`（含「光油」行数量，命中行数） | **0**（0 行） | **0**（0 行） |
| `z`（全部，行数） | **1700**（5 行） | **1280**（6 行） |
| `s = z−x−y` | **1700** | **880** |
| 输出段 | 只 1 段（x、y 均省） | 2 段（省光油段） |

★ **这就是 `omit_zero` 的两个边界用例**：
- `x=0, y=0` → 只输出「水性油墨1700公斤」（**不要**写成 `…水性油墨1700公斤，光油0公斤，原材料0公斤`）
- `y=0`     → 「水性油墨880公斤，原材料400公斤」（**不要**写光油段）

`omit_zero=False`（历史口径，广源那单仍是这种写法）会三段全写。**新客户默认 `True`。**

## 三、并发环境（这次专有的坑，见 SF-31 / SF-33）

- 执行期间同一账套有**另一个用户/组织**在跑成都批次（`AR109-*` / `SVINV0003366x~3368x`），
  残留「处理结果」失败窗（内容 `183306=XSCKD-101-202512-S0283`，**不是本批的单**）压在最上层拦点击。
- 处理：**先 dump 确认不是自己的单** → 真实鼠标关 ✕（`kd_stray.py --close`）→ 再跑。
- 事后清场时又观察到**别人新开的 4 个标签**（`销售退货单列表` / `凭证查询` / `凭证 - 修改` ×2）
  —— 说明**浏览器会话是共享的**，清场只能保证"自己的标签关掉了"，
  不要把看到的标签都当自己的。**看不到的标签不要动。**
- 记账影响：**单据号会跳号**（`-0001` 后直接 `-0003`），**跳号 ≠ 丢单，不要去补单**。

## 三、口径演进（注意别用错版本）

| 项 | 旧口径（2026-09-18 定） | **新口径（2026-09-21 定）** |
|---|---|---|
| 应收单业务日期 `FDATE` | 上个月最后一天（如 2026-08-31） | **月底 = 2026-09-30** |
| 应收单到期日 `FENDDATE_H` | 随 `FDATE` 自动联动 | **显式填月底 2026-09-30** |
| 专票业务日期 `FDATE` | 与应收单一致 | **月底 2026-09-30** |
| 专票发票日期 `FINVOICEDATE` | 自动带应收单业务日期 | **月底 2026-09-30** |
| 凭证摘要 | 保留原值 | **按 x/y/z/s 规则重写**（见上） |
| 专票分录 | 合并 | **不合并**（避免子单，见 `sub-bills-00000N.md`） |

其余不变：出库单按**单据日期 `FDate`（「日期」列）**区间筛（★ 2026-10-29 用户确认，不是账务日期
`FDate1`；区间形态常是上月 26 ~ 当月 25）；明细**每个物料一行**；
发票号**不填**；开票人取登录用户；复核人 = `config.yaml: rules.invoice_checker`。

# 性能基线：一家单位整链要多久（2026-09-22 实测）

> 来源：杭州小章那单的**真实日志时间戳**（不是估算），可直接拿来判断"这次跑得对不对"。

| 段 | 起止 | 耗时 |
|---|---|---|
| 出库单筛选（含过滤对话框）→ 应收单保存 + 提交 | 10:48:20 → 10:49:15 | **55s** |
| 应收单 → 专票保存 | 10:54:03 → 10:54:42 | **39s**（另有 30s 截图黑洞） |
| 业务凭证 → 改摘要 → 凭证保存 | 11:00:21 → 11:01:32 | **71s**（另有 60s 截图黑洞） |

- **有效执行 ≈ 165s（2 分 45 秒）**；截图黑洞 **90s**；合计 **255s ≈ 4 分 15 秒/家**
- 修掉 SF-34 后目标 **≈ 170s（2 分 50 秒）/家**
- ⚠️ 用户**实际感受**通常远大于此（本次是 ~40 分钟）—— 差额全在**定位单号 / 关残留弹窗 /
  探字段 / 断链后分步续跑**，不在机械执行本身。⇒ 提速重点在**别让流程断**（SF-35），
  而不是抠那几十毫秒的等待。
